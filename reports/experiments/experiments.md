# Experiments — summary of all recomputed entries

Each atlas entry marked 🟢 *recomputed* is an experiment: we re-run a published interpretability analysis on an open
model (or a model trained here), compare our measurement with the paper's number, and judge it against a criterion
in [`reports/planned-runs.md`](../planned-runs.md) that was meant to be written **before** the run. Rows whose analysis
or criterion was chosen after results had been seen are marked **post-hoc** with the reason and are not counted
(see the post-review section of planned-runs.md and [`../reviews/methods-review.md`](../reviews/methods-review.md)).
Rows whose claim starts with "Confirmatory:" are re-tests pre-stated and pushed on 2026-11-28 (commit `3090314`)
before they ran, with stronger controls, fresh data or more seeds; they are counted. Rows with a "CI rule" pass only if
the whole 95% CI meets the threshold and are partial (inconclusive) if it straddles it. Per-experiment details are in
`reports/experiments/<slug>/experiment.md` (setup, controls, results table, interpretation, deviations) and
`learnings.md` (what went wrong and how it was fixed). The table below is regenerated by `uv run python -m atlas.report`
from `results/<slug>/replication.json`. Do not edit it by hand.

## Key terms (plain language)

- **Activation patching / noising:** run the model on a clean prompt but swap one component's output for its output
  on a corrupted prompt. If the answer changes, that component carries information the task needs.
- **Mean-ablation / zero-ablation:** replace a component's output with its average output, or with zeros, to remove it.
- **Logit difference:** how much more the model prefers the right answer than a specific wrong one (in log-odds).
- **Probability difference (PD):** probability mass on correct continuations minus mass on incorrect ones.
- **Linear probe:** a linear classifier or regressor trained on activations. High held-out accuracy means the
  information is linearly readable, which does not prove the model uses it. Interventions test use.
- **Direct logit attribution (DLA):** a component's output projected straight onto the answer's unembedding direction.
- **Fourier basis / key frequencies:** writing a function on 0…P−1 as a sum of sines and cosines. A grokked model uses
  only a few frequencies.
- **Steering vector:** a direction added to the residual stream to change behaviour.
- **Sparse autoencoder (SAE) / transcoder:** an overcomplete dictionary trained to rewrite activations as a sparse sum
  of interpretable features.
- **Attribution graph:** for one prompt, the graph of direct effects between features, tokens and the output.
- **Verdict:** ✅ the pre-stated criterion holds; 🟡 partial (some sub-criteria hold); ❌ fails. "Published" columns
  quote the paper's number; "ours" are measured here, with 95% confidence intervals where computed (bootstrap for
  induction heads, IOI and greater-than; Wilson intervals for rates in refusal and calendar circles).
- **Post-hoc row:** a check whose metric, layer, selection rule or criterion was fixed after its results were seen, or
  that never had a pre-stated criterion. Shown, not counted.
- **Confirmatory row:** a new test of a claim, written down and pushed before it ran, usually because the earlier row was
  post-hoc, had a weak control or passed by a hair. Counted.
- **Wilson interval:** a 95% confidence interval for a rate (k of n) that stays within 0–100% and behaves well for small
  n. **Bootstrap CI:** resample the independent units (prompts, documents, stories, seeds) many times and take the
  middle 95% of the recomputed statistic.
- **Inconclusive (CI rule):** the 95% CI contains the pass threshold, so the data cannot say which side the true value
  is on. Shown as partial.
- **Permutation null:** shuffle the labels many times and see how often chance gives a result as strong as the real
  one; that fraction is the p-value.

## For a layman

Interpretability papers make claims like "this group of attention heads finds the name to repeat" or "the model stores
days of the week on a circle". We redo the measurements on public models with our own code and data and check whether
the claim still holds. Each row in the scoreboard is one such check, including the ones that fail.
